# HR-Analytics-Dashboard
# 1. Project Title
**HR Attrition Analysis Dashboard Using Power BI**

# 2. Short Description
The HR Attrition Analysis Dashboard is a data analytics project developed using Microsoft Power BI. It analyzes employee data to identify attrition patterns, understand workforce demographics, and explore factors influencing employee turnover. The project provides interactive dashboards that help HR teams gain meaningful insights and make data-driven decisions.

# 3. Tech Stack
- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculations and KPI development.
- **Excel / CSV** – Dataset handling and data source.

# 4. Data Source
The project uses an HR Employee Attrition dataset containing employee-related information, including:
- Employee demographics
- Department and job role
- Education and age
- Job satisfaction
- Monthly income
- Years at the company
- Employee attrition status

# 5. Features and Highlights

### Dashboard 1: HR Overview
- Total employee count.
- Employee attrition count.
- Overall attrition rate.
- Key HR performance indicators.
- Overall workforce analysis.

### Dashboard 2: Employee Insights
- Employee demographic analysis.
- Department-wise employee distribution.
- Job role analysis.
- Employee-related insights.
- Interactive filtering using slicers.

### Dashboard 3: HR Attrition Analysis
- Employee attrition analysis.
- Attrition by department and job role.
- Analysis of factors influencing employee turnover.
- Identification of employee attrition patterns.

### Key Highlights
- Three interactive dashboard pages.
- Dynamic slicers and filters.
- KPI cards and data visualizations.
- Data cleaning and transformation.
- Interactive and professional dashboard design.

# Example
**Business Scenario:**

An organization is experiencing employee turnover and wants to understand why employees are leaving.

Using this Power BI dashboard, HR managers can analyze employee attrition by department, job role, age group, and other employee factors.

For example, HR managers can identify departments with higher attrition rates and investigate possible reasons to support employee retention strategies.

# Project Outcome
Successfully developed an interactive three-page HR Analytics Dashboard using Power BI to analyze employee data, identify attrition patterns, and provide meaningful insights for better HR decision-making.
